# 다온 트랙 (데이터 분석가) 공통 설정

상위 규칙은 `docs/STORY_BIBLE_UNIVERSE.md`(§8), 형식은 `docs/storyboard/_TEMPLATE.md`. PM 트랙(`docs/storyboard/pm/`)과 같은 방식으로 쓴다. 이 폴더의 파일은 숫자로 시작하지 않으므로 `scripts/storyboard.mjs`가 DE편 `STORYBOARD.md`에 합치지 않는다.

## 트랙 한 줄
숫자를 믿고 쓰는 사람에서, 숫자가 어떻게 만들어졌는지 묻고 질문을 바꾸는 사람으로. DE편의 주니가 "안 만드는 용기"로 시니어가 되는 것처럼, 다온은 "대시보드를 만들지 않고 질문을 바꾸는 판단"으로 시니어가 된다.

## 공통 규칙

- DE편의 사건·숫자·대사는 바꾸지 않는다. 다온이 스스로 답을 찾는 Ch10 장면(주니의 질문 "이 숫자를 누가, 얼마나 자주 보나요?")은 정본 그대로 두고, D8은 그 *뒤*를 다룬다.
- 각 장은 독립 완결이다. 교차 사건은 장 안에서 한 번 요약한다.
- 수치는 모두 바구니 안의 가상 설정이다. 현실 세계의 통계나 비율에 대한 주장을 쓰지 않는다. 계산이 필요한 곳(D3, D5)은 값을 스토리보드에 직접 적어 검산할 수 있게 한다.
- 대명사 '그/그녀'를 쓰지 않는다. 이름과 직함으로 부른다.
